# Commerce Hub 11 (Kotlin / Jetpack Compose)

1. Zip ko repo ke root me extract karo (`images/` folder wahi rehne do, usme `icon-512.png` zaruri hai).
2. Push karo -> GitHub Actions "Build Android APK" chalega.
3. APK seedha: repo -> **Releases** -> latest -> `CommerceHub11.apk`
   (direct link: https://github.com/<user>/<repo>/releases/latest/download/CommerceHub11.apk)

Settings -> Actions -> General -> Workflow permissions = "Read and write" (Release banane ke liye).
